# MATH Qualified FLOOR and FLT

This example demonstrates qualified numeric conversion builtins from `MATH`.

## What it shows

- converting `INTEGER` to `REAL` with `MATH.FLT`
- converting `REAL` to `INTEGER` with `MATH.FLOOR`
- printing the final integer value through `IO`

## Source

- `src/Main.ob0`

## Run

From the repository root:

```bash
scripts/oberon0 examples/math-qualified-floor-flt --run
```

## Expected output

```text
7
```
